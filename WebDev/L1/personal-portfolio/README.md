Welcome to my personal portfolio! This website showcases my journey as a Computer Science student aspiring to become an AI Engineer, highlighting my technical skills, education, projects, and research interests.

My goal is to build intelligent, data-driven applications using Artificial Intelligence and Machine Learning to solve real-world problems.

## 🌐 About the Portfolio

This portfolio is designed with a clean, professional interface and a responsive layout to present my background, technical expertise, and development work in one place.

### ✨ Features

- **Home:** Introduction, professional role, and profile photo.
- **About Me:** Career goals, interests, and AI engineering aspirations.
- **Education:** Academic background and qualifications.
- **Skills:** Programming languages, machine learning, deep learning, data analysis, and web technologies.
- **Projects:** Showcases selected projects with descriptions, technology tags, preview images, and GitHub links.
- **Research Publication:** Highlights research work with a link to the paper PDF.
- **Contact:** Email, phone, location, GitHub, and LinkedIn details.
- **Responsive Navigation:** Mobile-friendly navigation menu.
- **Active Navigation:** Highlights the section currently in view.
- **Scroll Animations:** Adds reveal effects to selected content.
- **Smooth Scrolling:** Makes navigation between sections more comfortable.

## 🛠️ Technologies Used

- **HTML5** — Website structure and semantic content.
- **CSS3** — Styling, responsive layouts, transitions, and animations.
- **JavaScript** — Mobile navigation, active section highlighting, scroll reveal, and dynamic copyright year.
- **Google Fonts** — Poppins and Inter typography.
- **Git & GitHub** — Version control and project hosting.

## 🚀 Getting Started

You can run this project locally without installing any additional frameworks.

### 1. Clone the repository

```bash
git clone https://github.com/a-bhi2244/ai-engineer-portfolio.git
```

### 2. Open the project folder

```bash
cd ai-engineer-portfolio
```

### 3. Run the website

Open `index.html` in your preferred web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension for local development.
